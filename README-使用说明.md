# 字字岛

适合 iPad 的中文认读、听写和古诗练习。课程包含第二单元听写表的 77 个必学字词、20 个补充字词，以及《登鹳雀楼》和《望庐山瀑布》。两首诗参照[人民教育出版社的《登鹳雀楼》教学资料](https://www.pep.com.cn/bks/xxyw/jzjd/202505/W020250531428691312909.pdf)和[教育部课程标准](https://www.moe.gov.cn/srcsite/A06/s3331/201612/W020161213303084709835.pdf)核对。字词配有拼音提示。

## 安装到 iPad

1. 在 iPad 的 Safari 打开 [字字岛](https://wangxiaoyanwxy-hub.github.io/chinese-learning/)。
2. 点「分享」→「添加到主屏幕」。如果出现「作为网页 App 打开」，请保持启用。
3. 从主屏幕打开字字岛，联网等待页脚显示「离线内容已就绪」。之后可以离线打开和练习。

## 练习与管理

- 在目录选课，再按字词、拆成单字、或选择古诗的逐句／整首练习。默认全选，可以清空后逐个挑选，也可以打乱顺序。
- 认读默认隐藏拼音，按需看拼音或听朗读。听写先播题，可用 Apple Pencil、手指或纸笔写，再揭晓答案并自行评估。整首默写先显示诗题。
- 认读和听写各自保存「未练／已掌握／待复习」。错词本可分别挑选后重练。没有固定复习周期。
- 家长可以直接修改状态、添加或编辑本地课文、调节朗读语速。朗读由设备上的本地普通话语音提供。没有语音时可以让家长读题。在 iPad 的「设置 → 辅助功能」中找到朗读相关功能并下载普通话语音，菜单名称因系统版本而异。
- 在「家长管理 → 导入字词表」选择一张图片或一份 PDF。先联网加载识别组件，然后对照原表核对课名、必学词和补充词；改好后点「确认并保存」。可读文字的 PDF 会优先提取文字，扫描页会做图片识别。每次导入存为一课，原文件在设备上处理。
- 在「家长管理 → 导出备份」将 JSON 保存到「文件」。更换设备、清除网站数据或恢复前先备份。恢复会替换当前设备的进度、自定义课文和语速，应用会先显示确认对话框。
- 应用无需账号，学习记录和自定义课文保存在本机。只将此目录内的应用文件上传到公开仓库，备份文件和原始听写表应自行保管。

## GitHub Pages 部署与更新

将本目录的文件放在仓库 `main` 分支的根目录。在仓库的 `Settings → Pages` 选择 `Deploy from a branch → main → /(root)`，保存后可在 `Actions` 查看部署结果。保留仓库现有 README 也可以。

这是静态网站，无需构建。修改内置字库时保留课文 ID，更新任一应用文件时同步修改 `sw.js` 中的缓存版本。需要新增离线资源时，也把它加到 `sw.js` 的文件列表。新版就绪后，关闭旧页面和主屏幕应用，再重新打开。
